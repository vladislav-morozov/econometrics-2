Learning Algorithms

Think in terms of learning algorithms:

  1. Algorithm sees sample \(S=\curl{(Y_1, \bX_1), \dots, (Y_N, \bX_N)}\) and hypothesis class \(\Hcal\)
  2. Algorithm returns some \(\hat{h}_{S}(\cdot)\in\Hcal\)

Example of learning algorithm: ERM

Want algorithms that “tend to” return \(\hat{h}_S(\cdot)\) with “low” \(R(\hat{h}_S)\)

Bayes Risk

Special name for lowest possible risk:

Definition 1 The Bayes risk is defined as \[ R^* = \inf R(h(\bX)) \] across \(h(\cdot)\) such that \(R(h)\) makes sense

Note: \(R^*\) depends on the distribution of the data

Examples of Bayes Risk: Independent Coin
